# PVPTabTarget

PVPTabTarget is a lightweight **World of Warcraft addon** that improves **TAB targeting in PvP**.

In **Arenas and Battlegrounds**, TAB targets **enemy players only**, preventing accidental targeting of critters, pets, or NPCs.  
In **PvE content** such as **Dungeons and Raids**, TAB works normally and targets **all enemies**.

The addon automatically adapts targeting behavior depending on the zone you are in.

---

## Installation

Install via Ascensionn WoWUP:

[https://github.com/xZeroW/asc-wowup](https://github.com/xZeroW/asc-wowup)

Or download manually and place the addon in:

```

World of Warcraft/*retail*/Interface/AddOns/

```

---

## Features

- Automatic **PvP / PvE zone detection**
- Players-only TAB targeting in **Arenas & Battlegrounds**
- Normal targeting in **Dungeons & Raids**
- Smart keybinding override for **TAB / SHIFT-TAB**
- Minimap button for quick toggle and settings
- Customizable targeting modes
- Lightweight and performance-friendly
